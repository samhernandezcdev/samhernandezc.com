## System

- **Calculation engine (Python):** load distribution, component selection and
  geometry validation for each configuration.
- **Frontend (React/TypeScript):** builds configurations and compares capacity,
  cost and stock between options.
- **Delivery:** the full stack runs in Docker containers, with CI/CD, so
  development and production use the same environment.
