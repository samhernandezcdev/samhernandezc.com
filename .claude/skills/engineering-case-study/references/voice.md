# Voice

## Rules
- Plain verbs: built, designed, modeled, replaced, measured, moved, removed, migrated, documented.
- Concrete nouns: calculation engine, PostgreSQL schema, configuration workflow, background job, API boundary.
- One claim per sentence. Attach evidence immediately or drop the claim.
- First person, past tense for work done; present tense only for current work.
- Prefer "problem → what I did → what changed" over self-description.
- Fewer words. If a sentence survives deletion without loss, delete it.
- Titles are honest: "Software Engineer". No "Senior", "AI Engineer", "Architect" unless held as an actual title.

## Banned phrases (unless concrete evidence is attached in the same sentence)
- passionate, enthusiast, ninja, rockstar, guru
- cutting-edge, state-of-the-art, revolutionary, innovative solutions, next-generation
- high-precision, world-class, robust (as filler), seamless, best-in-class
- spearheaded, leveraged, synergy, empowered, drove digital transformation
- scalable solutions, digital experiences, amazing experiences
- "helping businesses grow", "operate better, automate and grow"
- "results-driven", "detail-oriented", "team player"

## Before → after (from CV wording)
| Before | After |
|---|---|
| "Architected a high-precision Engineering Platform for lifting system configuration…" | "Built an internal engineering calculation and configuration platform: a deterministic Python calculation engine, server-side validation, PostgreSQL persistence and a React frontend." (Never "quoting", "pricing" or "CPQ": the platform does not own price or quotation.) |
| "Engineered a domain-specific Calculation Engine… formalizing complex regulatory logic into reproducible, auditable workflows." | "Implemented a deterministic calculation engine from engineering rules validated by domain specialists." (Specialists own the formulas; do not claim auditability as a requirement.) |
| "Containerized the full application stack… accelerated internal validation cycles…" | "Set up a Docker-based environment for development and deployment." (no CI/CD or speed claims unless verified) |
| "Led IT strategy engagements from discovery to delivery…" | "Ran requirements workshops and wrote architecture decision records for client systems." |

Note: in the anonymized case study, do not name the specific standards or company products if that would identify the employer's proprietary system; the Experience entry may name the employer.
